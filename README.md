# 🚀 AI Productivity Playbook

A centralized, version-controlled library of AI prompts and workflows I use to streamline daily tasks, generate content, and simplify repetitive work. 

## 🛠️ How I use this
Instead of rewriting prompts every day, I treat my prompts like code. I document, test, and refine them here. This ensures consistent, high-quality outputs from AI tools and saves hours of manual drafting.

## 📂 Contents
- `prompts/meeting-summarizer.md`: Turns messy transcripts into clean summaries and action items.
- `prompts/content-repurposer.md`: Transforms long-form text into multi-platform social content.
- `prompts/email-drafter.md`: Generates tone-adjusted emails for complex communications.
